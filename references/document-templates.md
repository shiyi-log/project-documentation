# 文档模板

使用能够回答请求的最小模板。替换占位内容；最终文档不得留下 `TBD` 或编造的事实。

## README / 入口文档

```markdown
# 项目名称

## 用途
说明项目解决的问题。

## 当前状态
说明什么可用、什么是部分完成、什么尚未实现。

## 快速开始
列出在声明环境中验证过的命令和前置条件。

## 范围
说明包含内容和明确排除内容。

## 更多文档
在存在时链接安装、架构、API、运维或安全文档。
```

## 架构文档

```markdown
# 架构

## 上下文与范围
系统边界和受众。

## 组件与数据流
模块、依赖和重要状态转换。

## 契约与权威来源
说明每条规则由哪个 API、Schema、生成产物或代码负责。

## 失败与恢复
超时、重试、部分成功、回滚限制和操作员动作。

## 验证与限制
说明已检查内容、未运行内容和仍不确定的部分。
```

## 运行手册

```markdown
# 运行手册

## 前置条件
环境、权限、依赖和配置。

## 启动 / 停止 / 部署
命令和预期结果。

## 健康状态与日志
在哪里检查状态，以及哪些信号重要。

## 失败与恢复
安全诊断、回滚、修复和升级处理。

## 备份与数据丢失
恢复点、恢复时间、不可逆动作和限制。
```

## 决策记录

```markdown
# 决策：<简短标题>

## 上下文
什么因素迫使我们做出选择。

## 决策
选择了什么。

## 备选方案
考虑过什么，以及为什么拒绝。

## 后果
收益、成本、限制和后续工作。
```
